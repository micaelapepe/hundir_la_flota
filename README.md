# 🚢 Hundir la Flota en Python

Proyecto desarrollado en equipo para el RETO nº 1, implementando el clásico juego de mesa **Hundir la Flota** en la consola de Python utilizando coordenadas alfanuméricas (ej. `A5`).

## ⚙️ Requisitos previos:

* **Python** (versión recomendada: **3.13 o superior**).
* **Librerías externas**: Este proyecto utiliza `numpy` para el manejo de estructuras de datos.

---

## 📦 Instalación y Configuración:

1. #### Instalar Python en su ordenador (si no lo tiene).
2. Abrir la terminal
3. Ejecutar:
   #### pip install -r requirements.txt para instalar numpy.
5. Ejecutar el juego con:
   #### python main.py.

   
## 🕹️ Instrucciones del juego:

1. Coloca tus barcos en el tablero, cuidado y no los coloques fuera del tablero.
2. Los barcos se sitúan en el tablero escribiendo: ("A",1)
3. Una vez, situados todos los barcos en el tablero, dale al enter para que empiece la partida contra el ordenador.
4. Empieza el jugador "humano" disparando contra su adversario diciendo las coordenadas de su disparo: ("A", 3).
5. Si el jugador "humano" hunde todos los barcos del jugador "ordenador" ha ganado la partida.
